Ardian is my personal fork of Ardia (ardia.dev) by x.com/barre_of_lube.

## What's changed from Ardia

- Renamed the app you see to Ardian. The built app is Ardian.app, and the bundle id is com.almostfictive.ardian.
- Replaced the app icon. See Icon attribution.
- The toolbar backdrop is a floating glass pill when glass is on. The address row shows the site name, plus reload, screenshot, site settings, split view and downloads.
- Back and forward sit at the top of the sidebar.
- The bookmarks bar defaults to new tabs only, and it hides when the folder is empty. Always is gone from the menu. A saved Always setting still shows the bar.
- Setup no longer plays music, and the mute button on the intro is gone.
- The new tab no longer shows the animated logo, the check-in, the telemetry question, the personalize button, or the release-notes postcard. Release notes still open if you ask for them.
- Removed Send Feedback from the menus.
- Command-9 selects the ninth tab instead of the last one. Selected tabs do not glow unless you turn that back on.
- Sidebar shortcuts start as Home, Extensions, Bookmarks and Downloads. You can add a website, remove one, or move them. Holding Command numbers the first nine.
- WhatsApp, Slack and Telegram open in a panel beside the page, not a new tab. Discord, Gmail and Calendar are optional. Private windows hide these.
- Each profile can have workspaces, with a switcher in the sidebar. The window remembers which one is open.
- The sidebar footer has a profile menu for switching profiles and a few window commands.
- The camera button can capture the visible area, a selection, or the full page, then mark it up and copy it or save a PNG or PDF.
- Right-clicking a web page includes Settings, even when no text is selected.
- Live Folders no longer has its own settings page. Opening it shows General.
- Light and dark colours are more solid, and panels and sheets use a rounder corner.
- An ad-hoc release workflow builds an unsigned app zip. There is no automatic update inside the app.
- scripts/ardian-local and preview-ardian.command build and open a local preview from Ardia's published engine. update-ardian.command replaces Ardian in Applications with the latest GitHub release zip, and it does not check a signature.
