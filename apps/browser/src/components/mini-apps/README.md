The mini-app dock opens small web apps over the current browser window.
Each card keeps its web view alive after first open.
Mini-app pages use the current Ardia profile's engine identity.
The dock and cards render from the sidebar.
Private windows do not show mini-apps.
Remove the two component renders in the sidebar to turn the feature off.

Settings › General accepts custom HTTP(S) app URLs alongside the built-in apps.
Custom URLs are stored in the synced sidebar mini-app list and can be removed in Settings.
