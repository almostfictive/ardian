Workspaces provide separate tab sets inside a browser window.
Each profile has exactly three workspaces; missing saved slots are filled automatically.
Swipe left or right in the sidebar to switch workspaces.
The switcher sits in the sidebar above the profile control.
Each tab is assigned to the active workspace when created.
Tabs from other workspaces stay in the window and are frozen while hidden.
Workspace choices and the last active tab are saved with the session.
Remove the switcher render and its browser state hooks to turn this off.
